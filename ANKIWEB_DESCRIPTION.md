Shows which ease button (Again / Hard / Good / Easy) you just pressed as a color-coded label in the top-right corner of the main window, then auto-hides it after 1.5 seconds. Handy for confirming you pressed the button you meant to, especially when answering with keyboard shortcuts.

Features:

- Color-coded per ease (red/orange/green/blue)
- Configurable language for the labels: English or Irish (Gaeilge)
- Optional "always show" debug mode for tweaking position/styling

Configure via Tools → Add-ons → Show Answer Button Pressed → Config.

Inspired by Color Confirmation (https://ankiweb.net/shared/info/1084228676), independently implemented.
